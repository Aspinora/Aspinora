SSC CGL

SSC CGL

Duration: 60 Mins Maximum Marks: 200

Read the following instructions carefully.

  1. The test contains 4 sections having 100 questions.
  2. Each question has 4 options out of which only one is correct.
  3. You have to finish the test in 60 minutes.
  4. You will be given 15 minutes to complete each section.
  5. You will be awarded 2 marks for each correct answer and 0.5 will be deducted for each wrong answer.
  6. There is no negative marking for the questions that you have not attempted.

Please note all questions will appear in your default language. This language can be changed for a particular question later on.
